# Deploy Banger Studio to Railway (2 minutes)
1. Create a GitHub repo (any name, e.g. `banger-studio`).
2. Add exactly two files to it: `banger-studio-app.html` and `Dockerfile` (both in this download set).
3. Tell Claude the repo name as `yourusername/banger-studio` — Claude triggers the Railway deployment from the chat and gives you the live URL.
(Or right now, no deploy needed: open `banger-studio-app.html` in Chrome on your phone — the full app runs from the file.)
